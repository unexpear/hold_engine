Five pillars. All non-negotiable.

ADR 0003 picks five fronts to compete on, picks five non-goals to refuse, and ships the discipline as the artifact. Each pillar gets its own card below — currently greyboxed.

Junior note · Pillar grid

What goes in each card

  • One pillar per card — drawn from docs/adr/0003-differentiation-and-competitive-posture.md
  • Each card: number (P1–P5) · pillar title · one-sentence promise · one specific receipt linking to the ADR section that backs it
  • Real receipt examples to use:
    • P1 — "MIT forever. No royalties, ever." → ADR 0003 §"Pillar 1: Economics and trust"
    • P2 — "<10MB binary, sub-second cold start, hot reload that doesn't lie." → ADR 0003 §"Pillar 2: Iteration speed" + ADR 0004 (full)
    • P3 — "One scene file. Editor and runtime read the same bytes." → ADR 0003 §"Pillar 3: Editor-runtime unification"
    • P4 — "Same seed, same input, identical state. CI-pinned." → ADR 0003 §"Pillar 4: Determinism" + ADR 0005
    • P5 — "Zero external crates. Every byte auditable." → ADR 0003 §"Pillar 5: Footprint and source quality"
  • Visual: small numeric prefix in JetBrains Mono Stone, then Fraunces title, then 2-3 lines of Stone-colored body
  • No icons. No emoji. No left-border accents. The number IS the visual.

Junior note · Comparison table

Honest comparison, not marketing chart

  • Three columns: Hold · Unity · Unreal. We take the rightmost (us) column. No fake "winners and losers" graphic.
  • Symbols: ✓ Forest for "have it" · ✗ 30%-Ink for "don't" · never red
  • Real rows below as a starting set — every claim must be sourced before it ships:
    • Royalties — Hold 0%, Unity tiered, Unreal 5% over $1M (gross)
    • Source code access — Hold full+MIT, Unity binary-only on free tier, Unreal source available
    • Engine binary size — Hold <10MB, Unity ~250MB editor, Unreal ~50GB editor
    • Hot reload that survives — Hold yes (ADR 0004 Q14a entity diff), Unity partial, Unreal partial
    • Deterministic by default — Hold yes (ADR 0005 harness), Unity opt-in (DOTS only), Unreal partial

    • Required online for core dev — Hold no, Unity sign-in often, Unreal sign-in often
    • Phone-home telemetry — Hold no, Unity yes (opt-out historically painful), Unreal opt-in
  • One row I'm not putting in: "AAA graphics features" — Unreal wins that decisively for now and pretending otherwise would burn the credibility we just built

The editor is the runtime.

You do not switch out of "edit mode" to test your game. You play it inside the editor, you tweak a value and the value changes, you save the file and the file is what ships.

Junior note · Receipts section

Why this section exists at all
